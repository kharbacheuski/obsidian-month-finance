# Finance Tracker for Obsidian

Плагин для управления личными финансами прямо в Obsidian. Данные хранятся в обычной markdown-таблице, а плагин рендерит ниже неё **отдельные секции-карточки**: сколько потрачено за месяц, средний расход в день, сколько отложено в сбережения и bar-график трат по категориям.

## Возможности

- 📝 **Таблица — просто markdown** — источник данных остаётся обычной md-таблицей, плагин её не трогает и не скрывает.
- 💸 **Потрачено за месяц** и **средний расход в день** — расходы без сбережений. Средний расход делится на число дней, прошедших по записям таблицы, а «non-zero-days» — на число дней, в которые реально были траты.
- 🐷 **Накопления в разных валютах** — карточка со списком накоплений из frontmatter `totalSavings` (например, `0.40 ETH`, `1500 USD`), а мелкой строкой — сколько отложено за месяц. Если `totalSavings` не задан, крупно показывается нетто за месяц.
- 📈 **Bar-график трат по категориям** — горизонтальные бары с процентами и стабильными цветами категорий. Категории с точкой (`Еда.Продукты`) объединяются в одну строку и делятся на цветные сегменты.
- 🎯 **Бюджет по категориям** — сворачиваемый блок со столбчатой диаграммой: лимиты задаются во frontmatter, заливка показывает, насколько они израсходованы.
- � **ТОП расходов** — таблица самых крупных трат месяца с суммой и долей от всех расходов; сворачивается в аккордеон.
- �🎨 **UI в стиле Obsidian** — использует CSS-переменные темы (тёмная и светлая), адаптирован под мобильные экраны.

## Как пользоваться

1. Установите плагин и включите его.
2. Нажмите на иконку кошелька в ленте слева или выполните команду **«Создать финансовую заметку»** — будет создана заметка с текущей датой (например, `11.11.2026.md`) и готовой таблицей.
3. Записывайте операции в таблицу. Карточки обновятся автоматически.

## Настройки

Плагин добавляет вкладку настроек (**Настройки → Month Finance**):

- **Валюта** — BYN, USD, EUR, RUB или своя (произвольный символ). Используется на карточках, когда в заметке валюта не задана во frontmatter.
- **Исключать накопления из среднего расхода** — если включено (по умолчанию), траты на накопления не учитываются в среднем расходе за день.
- **Доп. категории накоплений** — свои ключевые слова через запятую, которые плагин будет считать накоплениями.
- **Дней в месяце** — делитель для среднего расхода, когда в таблице не заполнен день.

Раздел **Секции дашборда** — чекбоксы, которыми можно полностью убрать блоки из заметки:

- **Показывать бюджет** — включает сворачиваемый блок «Бюджет по категориям». Сами лимиты задаются в заметке (frontmatter `budget`), а не в настройках — они относятся к конкретному месяцу.
- **Показывать ТОП расходов** — включает сворачиваемую таблицу с самыми крупными тратами месяца.
- **Сколько трат выводить** — число строк, вводится вручную (от 1 до 100, по умолчанию 5). Пункт недоступен, пока таблица выключена.

## Формат таблицы

Таблица должна находиться в заметке с frontmatter `finance: true`. Колонки распознаются по заголовкам (рус./англ.):

| Колонка   | Заголовки (пример)      | Описание                              |
| --------- | ----------------------- | ------------------------------------- |
| День      | `День`, `Day`           | День месяца (1–31). Если пусто — берётся ближайший прошедший день |
| Тип       | `Тип`, `Type`           | `Доход` / `Расход` (приход/уход)      |
| Категория | `Категория`, `Category` | Например: Продукты, Сбережения        |
| Название  | `Название`, `Name`      | Что за операция                       |
| Сумма     | `Сумма`, `Amount`       | Число; знак «−» = расход, «+» = доход |

```md
---
finance: true
currency: "₽"
---

| День |  Тип   | Категория  | Название             | Сумма |
| :--: | :----: | :--------- | :------------------- | ----: |
|  01  | Доход  | Зарплата   | Зарплата за месяц    | 50000 |
|  03  | Расход | Продукты   | Продукты за неделю   | -1200 |
|  08  | Расход | Сбережения | Перевод в сбережения | -2000 |
```

Порядок колонок может быть любым, «Сумма» обязательна. Если тип не указан, он определяется по знаку суммы. Валюта задаётся в frontmatter (`currency`); если она не задана, используется валюта из настроек плагина.

Если в строке не заполнена колонка «День», плагин подставляет **ближайший прошедший день** — последний заполненный выше в таблице. Поэтому серию трат за одно число можно не нумеровать каждую:

```md
| День |  Тип   | Категория | Название             | Сумма |
| :--: | :----: | :-------- | :------------------- | ----: |
|  03  | Расход | Продукты  | Продукты за неделю   | -1200 |
|      | Расход | Кафе      | Обед                 |  -15  |
|      | Расход | Транспорт | Метро                |  -2   |
```

### Категории и подкатегории

Категорию можно задавать иерархически через точку: `Еда.Продукты`, `Еда.Рестораны`, `Еда.Продукты.Молочные`. На bar-графике все подкатегории одного родителя (`Еда`) показываются **одной строкой**, разделённой на сегменты в оттенках цвета родителя. Наведите курсор на сегмент — появится подсказка с названием подкатегории и суммой трат по ней; наведите на название строки — увидите разбивку по всем подкатегориям.

```md
| День |  Тип   | Категория        | Название           | Сумма |
| :--: | :----: | :--------------- | :----------------- | ----: |
|  02  | Расход | Еда.Продукты     | Продукты за неделю | -1200 |
|  05  | Расход | Еда.Рестораны    | Ужин с друзьями    | -800  |
```

### Бюджет по категориям

Категории можно задать лимит на месяц во frontmatter заметки — в поле `budget`. Лимит указывается для категории верхнего уровня (без подкатегорий):

```yaml
---
finance: true
currency: "₽"
budget:
    Еда: 5000
    Транспорт: 1000
    Развлечения: 2000
---
```

Тогда в дашборде появляется отдельная **столбчатая диаграмма «Бюджет по категориям»**. Все столбики одной высоты (100% = лимит), а заливка показывает, какая доля лимита уже израсходована:

- цвет заливки совпадает с цветом категории в графике «Траты по категориям»;
- под столбиком — название категории и сумма лимита, сверху — процент использования;
- при превышении лимита рядом с процентом показывается перерасход в скобках (`132% (−600 ₽)`), красным;
- при наведении на столбик показывается подсказка: потрачено / лимит, процент, остаток или перерасход;
- в шапке карточки — суммарный итог по всем бюджетам с общей полосой прогресса.

Бюджет сравнивается с тратами **без накоплений**. Если для категории лимит задан, а трат ещё не было, она всё равно показывается с 0%.

**Иерархические категории.** Бюджет понимает точечную нотацию так же, как и основной график:

- лимит на родителя (`Еда: 5000`) учитывает все его подкатегории — `Еда.Продукты`, `Еда.Рестораны` и т. д.;
- лимит на подкатегорию (`Еда.Продукты: 2000`) считает только её траты;
- можно задать оба сразу — в диаграмме появятся две отдельные колонки: общая по `Еда` и отдельная по `Еда.Продукты`;
- цвет подкатегории берётся у родителя, так что визуально видно, к какой группе она относится.

**Накопления.** Категориям-накоплениям тоже можно задать сумму в `budget` — это будет цель «отложить за месяц»:

```yaml
budget:
    Накопления: 5000
```

Считается по фактическим переводам в накопления. Для таких столбиков логика инвертирована: при достижении цели (100% и больше) процент становится зелёным, а в подсказке пишется «Цель выполнена» вместо «Перерасход».

Диаграмму можно выключить в настройках плагина (**Секции дашборда → «Показывать бюджет»**). Блок сворачивается кликом по заголовку — как и таблица «ТОП расходов»: справа в заголовке показывается общий процент использования бюджета (красным при перерасходе).

### ТОП расходов

Ниже графиков выводится таблица **«ТОП расходов»** — самые крупные траты месяца:

- строки отсортированы по сумме, рядом показана доля траты от всех расходов (без накоплений);
- одинаковые операции (совпадают «Название» и «Категория») суммируются в одну строку, в колонке «День» тогда показывается `×N` — число операций (наведите курсор, чтобы увидеть точное значение);
- цветная точка слева совпадает с цветом категории в графике «Траты по категориям»;
- справа в заголовке — сумма всех трат из таблицы;
- клик по заголовку сворачивает и разворачивает таблицу (аккордеон).

Число строк и показ таблицы настраиваются в разделе **Секции дашборда** в настройках плагина. Если в таблице нет колонки «Название», вместо описания используется категория.

### Средний расход в день

- **Средний расход в день** = расходы без сбережений ÷ число дней, прошедших по календарю записей (последний день, который встречается в таблице). Если в таблице есть записи 1, 2, 7 и 8 числа, сумма делится на 8. В настройках можно включить учёт накоплений в этом расчёте.
- **Non-zero-days расход** = расходы без сбережений ÷ число дней, в которые реально были траты. Для того же примера — деление на 4 (3–6 числа трат не было).

Если колонка «День» не заполнена, средний расход считается по числу дней из настроек (по умолчанию 30).

### Сбережения

Расходы в категориях-сбережениях не попадают в «Потрачено за месяц» и в bar-график — они суммируются в «Накопления за месяц» и показываются мелкой строкой в карточке накоплений. По умолчанию распознаются категории, содержащие: _сбережен_, _накоплен_, _savings_, _сэйвинг_, _вклад_, _инвест_, _копилка_. Можно задать свою категорию в frontmatter:

```yaml
---
finance: true
currency: "₽"
savingsCategory: "Сбережения"
---
```

**Снятие из накоплений.** Если в категории-накоплении указан тип `Доход`, это трактуется как «взяли из накоплений», и сумма вычитается из отложенного за месяц:

| День |  Тип   | Категория  | Название              | Сумма |
| :--: | :----: | :--------- | :-------------------- | ----: |
|  08  | Расход | Накопления | Отложил в копилку     |  -300 |
|  20  | Доход  | Накопления | Снял из копилки       |   700 |

Итог «Накопления в этом месяце» = `300 − 700 = −400`, и подсказка в карточке накоплений покажет именно отрицательное значение.

В диаграмме бюджета отрицательного значения быть не может (нельзя «вложить минус»): если нетто по накоплениям ушло в минус, столбик показывает `0` и `0%`, а в подсказке — весь лимит в «Осталось».

Общие накопления на текущий момент задаются в frontmatter `totalSavings` — можно одной суммой в базовой валюте, а можно списком в разных валютах (каждая запись — `сумма ВАЛЮТА`):

```yaml
---
finance: true
currency: "₽"
totalSavings:
    - 0.40 ETH
    - 1500 USD
    - 2500 BYN
---
```

Эти значения показываются крупно в карточке «Всего накоплено», а «отложено в сбережения за месяц» — мелким шрифтом под ними. Если `totalSavings` не задан, карточка просто показывает сумму, отложенную за месяц.
